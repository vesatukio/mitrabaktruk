# Mitra Bak Truk Wahyu Jati

Website informasi untuk **Mitra Bak Truk Wahyu Jati**, mitra pemasaran/penghubung calon pelanggan dengan bengkel di Clapar, Subah, Kabupaten Batang, Jawa Tengah.

## File situs
- `index.html` — halaman utama responsif dengan metadata SEO dasar dan data terstruktur.
- `robots.txt` — arahan perayapan.
- `sitemap.xml` — sitemap untuk mesin pencari.

## Publikasi GitHub Pages
Di GitHub buka **Settings → Pages**, pilih **Deploy from a branch**, pilih branch **main** dan folder **/(root)**, lalu tekan **Save**. Setelah proses selesai, alamat proyek biasanya:
https://vesatukio.github.io/mitrabaktruk/

## Catatan
Situs ini mewakili mitra pemasaran, bukan klaim kepemilikan bengkel. Periksa semua detail layanan, alamat, nomor kontak, dan informasi penawaran sebelum dipublikasikan. Tombol kontak saat ini mengarah ke halaman Google Sites lama dan bisa diganti setelah URL WhatsApp yang benar tersedia.
